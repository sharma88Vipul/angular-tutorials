Angular Tutorials 🚀
A collection of hands-on, beginner-to-advanced tutorials for learning Angular — the platform for building web applications with TypeScript. Each tutorial focuses on a specific concept with clear explanations and working code examples.
📖 About
This repo is meant to be a learning resource for anyone starting out with Angular or looking to sharpen specific skills. Tutorials are organized by topic and difficulty level, and each one includes:
A short explanation of the concept
Step-by-step code walkthrough
A runnable example project (where applicable)
Notes on best practices and common pitfalls
🗂️ Topics Covered
Angular basics (CLI, project structure, modules)
Components & templates
Data binding (interpolation, property, event, two-way)
Directives (structural & attribute)
Services & dependency injection
Routing & navigation
Forms (template-driven & reactive)
HTTP client & API integration
RxJS & observables
State management
Testing (unit & e2e)
Deployment
(Update this list as tutorials are added.)
🛠️ Prerequisites
Node.js (LTS recommended)
Angular CLI
```bash
  npm install -g @angular/cli
  ```
Basic knowledge of HTML, CSS, and JavaScript/TypeScript
🚀 Getting Started
Clone the repo
```bash
   git clone https://github.com/<your-username>/angular-tutorials.git
   cd angular-tutorials
   ```
Navigate into a tutorial folder
```bash
   cd tutorials/01-getting-started
   ```
Install dependencies
```bash
   npm install
   ```
Run the app
```bash
   ng serve
   ```
Open your browser at `http://localhost:4200`
